<bdi dir="rtl">عميل <bdi dir="ltr">Windows App</bdi> مع مضيف <bdi dir="ltr">Microsoft Dev Box</bdi>، أو بيئة <bdi dir="ltr">Windows RDP</bdi> أخرى: حافظ على نقر وكيل <bdi dir="ltr">computer-use</bdi> وكتابته والتقاطه للشاشة بعد اكتشاف الانقطاع؛ لا تراقب نافذة الاتصال باستمرار (التصغير يتطلب عرضًا متوافقًا تم التحقق منه)؛ أعد استخدام جلستك المسجّل دخولها دون حفظ كلمات مرور أو دخول تلقائي.</bdi>

تبقى وحدة التحكم غير مقفلة؛ اتبع السياسات. تصغير Windows Sandbox غير متحقق منه.

<img src="../../assets/keep-desktop-interactive.png" width="700" alt="قبل قطع RDP أو تصغير النافذة وبعده: قد تستمر التطبيقات بينما يتوقف النقر والكتابة والتقاط الشاشة؛ يساعد نقل الجلسة إلى وحدة التحكم والعميل المتوافق.">

- **استمرار إدخال الوكيل بعد الانقطاع:** حافظ على النقر والكتابة والتقاط الشاشة في سطح المكتب الحالي بعد اكتشاف Windows انقطاع RDP؛ قد يستغرق اكتشاف فقد الشبكة وقتًا.
- **لا تراقب نافذة الاتصال باستمرار:** ابتعد عن النافذة البعيدة؛ يتطلب التصغير عرض عميل متوافقًا واختبار إدخال مستقلًا ناجحًا في بيئتك.
- **أعد استخدام العمل المسجّل دخوله:** احتفظ بالجلسة والتطبيقات المفتوحة دون حفظ كلمات مرور أو تفعيل الدخول التلقائي؛ لا تسجّل الأداة دخولك بعد إعادة التشغيل.

رسم مفاهيمي بعناوين إنجليزية، لا اختبار مباشر. دعم العميل والقفل المحلي مع حاسوب محمول مستيقظ مشروطان.

> **يترك نقل الجلسة سطح المكتب البعيد مفتوحًا دون قفل.** من يستطيع تشغيل وحدة التحكم الفعلية أو التفاعلية للجهاز الافتراضي يمكنه استخدام الجلسة دون تسجيل الدخول إلى Windows. لا تستخدم حاسوبًا مشتركًا متاحًا للآخرين أو وحدة تحكم غير موثوقة. لا يدعم التشغيل خلف شاشة مقفلة أو تجاوز السياسات. [الإعداد ومخاطر الوصول](../configuration.md).

فقط حيث تسمح السياسات بإعداد نقل RDP/وحدة التحكم؛ تحقق من بيئتك، دون اعتماد شامل لتكوينات Dev Box.

[الإعداد ومخاطر الوصول](#setup) → [تحقق من الإدخال الفعلي](#proof) · [الحدود](#limits) · [التراجع](#undo) · تصغير Windows Sandbox: لم يُتحقق منه بعد.

**[Windows Sandbox](https://learn.microsoft.com/en-us/windows/security/application-security/application-isolation/windows-sandbox/) — نافذة مصغرة؛ مرشح لم يُتحقق منه:** عندما تُصغّر نافذة Windows Sandbox على المضيف ويستمر الضيف وتطبيقاته في العمل، هل يستمر النقر والكتابة والتقاط الشاشة؟ لم يُتحقق من النشر واستمرار الإدخال؛ قد تعمل هذه الأداة أو لا تعمل مع عرض عميل Sandbox أو نقل الضيف، ويلزم اختبار مستقل وليست حلًا مثبتًا.

## Windows App / RDP

يحاول التشخيص المثبت النقر والكتابة والالتقاط بعد نحو 10 ثوانٍ من كل انقطاع RDP للمستخدم المهيأ، حتى الاستخدام العادي، وقد يتعارض مع الوكيل. لا خيار موثق للمشغل لتعطيل التشخيص وحده؛ إزالة المضيف تزيل النقل أيضًا.

مسار Windows App/RDP: الانقطاع يستخدم نقل المضيف، والتصغير يستخدم عرض عميل متوافق وإعداد المضيف. احتفظ بإعداد الحاسوبين الذي اختُبر وتحقق من كل وضع. لا تكامل أو تشغيل للوكلاء ولا حفظ كلمات مرور أو دخول تلقائي. [→](../configuration.md#mode-choice)

أبلغ المشرف عن نجاح قفل الشاشة المحلية فقط على الاقتران المختبر مع محمول مستيقظ وعميل مهيأ، لا القفل البعيد؛ إغلاق الغطاء/فقد الشبكة يحتاج اكتشاف Windows للانقطاع.

## Windows Sandbox — UNVALIDATED

Sandbox تجربة مقترحة: توقف إن لم تُثبت طريقة نشر/اختبار معتمدة وقابلة للعمل. سجّل نقرًا وكتابة والتقاطًا غير حساس والنافذة ظاهرة؛ صغّر خلال فترة مسجلة مع استمرار الضيف والتطبيقات، وكرر الإدخال والتقاطًا جديدًا ثم أعد النافذة وافحصها. لم يُتحقق منه؛ عند الفشل أبقِ النافذة ظاهرة. خطوات RDP للحاسوبين والانقطاع والإغلاق/إعادة الفتح ليست إجراء Sandbox. [→](../configuration.md#sandbox-minimized-window-experiment)

<a id="setup"></a>

قبل التثبيت: أبقِ المضيف مشغّلًا ومستيقظًا وغير مقفل، وتأكد من سماح السياسات بهذا الاستخدام. متطلبات Windows وموافقة المسؤول وGit وPowerShell 5.1 وVBScript أدناه.

## حاسوبان

المضيف البعيد هو حاسوب Windows أو آلة افتراضية تشغّل الأتمتة؛ والعميل المحلي هو حاسوب Windows يشغّل RDP/Windows App. تحتاج إلى Windows PowerShell 5.1 وVBScript وGit للاستنساخ. يتطلب تثبيت المضيف موافقة المسؤول. احصل على نسخة جديدة موثوقة في مجلد المستخدم الحالي الخاص على كلا الحاسوبين، وليس في مجلد مشترك قابل للكتابة.



<details>
<summary>Windows App / Microsoft Dev Box / Hyper-V</summary>

> **Windows App هو عميل الاتصال؛ Microsoft Dev Box محطة عمل سحابية مُدارة. الخطر هو وصول شخص آخر إلى وحدة التحكم غير المقفلة، وليس انعدام أمان المنتج ذاته. المضيف المُدار لمطوّر واحد دون مسار وصول تفاعلي إلى وحدة التحكم لأشخاص غير موثوقين أقل خطراً من حاسوب مشترك. لا تفترض أن Microsoft Dev Box يتيح هذا المسار. التزم بسياسات مؤسستك: لا تتيح الأداة الأتمتة خلف شاشة بعيدة مقفلة ولا تتجاوز سياسات القفل.**

</details>

<a id="proof"></a>

- بعد أن يكتشف Windows انقطاع RDP، تُنقل الجلسة الحالية إلى وحدة التحكم للمساعدة في استمرار إدخال GUI.
- يساعد إعداد العرض العملاء المتوافقين عند تصغير النافذة؛ اختبر هذا الوضع على حدة.
- تحقق من النقر والكتابة والالتقاط الفعلي بنتائج خاصة تطابق الوضع، لا من استمرار التطبيقات وحده.

قبل الاختبار سجّل وقت البدء، وأوقف أي أتمتة UI أخرى، واحفظ العمل الحساس وأبعد النوافذ السرية؛ الانقطاع يشغّل التشخيص تلقائيًا. تحقق من أن وقت تعديل الملف أحدث من وقت بدء الاختبار المسجّل، وأن <bdi dir="ltr">Passed</bdi> و<bdi dir="ltr">Mode</bdi> يطابقان النتيجة المطلوبة. ثم جرّب نقرًا وكتابة والتقاطًا غير ضار في تطبيق ممثل بدقة وحدة التحكم الناتجة. التشخيص لا يثبت كل التطبيقات. [→](../configuration.md#reported-compatibility-evidence)

## التحقق الأول

اقطع اتصال RDP بالطريقة المعتادة، وانتظر 30 ثانية ثم أعد الاتصال؛ يعمل التشخيص تلقائياً. لاختبار التصغير المنفصل، نفّذ الأمر التالي على المضيف البعيد ثم صغّر نافذة الاتصال على العميل فوراً وأبقها مصغّرة 90 ثانية قبل استعادتها. ينتظر الاختبار 60 ثانية قبل الإدخال الفعلي والتقاط الشاشة.

## الحدود

الإعداد موثّق لبرنامج Remote Desktop Connection التقليدي؛ يعتمد دعم Windows App على الإصدار. أفاد مسؤول صيانة المشروع بأن زوج العميل والمضيف الأصلي اجتاز اختبار التصغير قبل تعزيز الأمان، لكنه لم يُختبر مجدداً بعد النشر. هذا لا يثبت دعم جميع العملاء. بعد إعادة التشغيل، سجّل الدخول وافتح القفل مرة واحدة ثم أعد تشغيل التطبيقات والأتمتة. أسطح المكتب دون واجهة رسومية غير مشمولة. قد يوقف القفل البعيد والسكون وإيقاف التشغيل وتسجيل الخروج الأتمتة. [جميع الحدود](../configuration.md#requirements-and-limitations).

إذا ظهر `Passed: false` فاقرأ `Error` و`Stage` والسجلات. إذا كانت النتيجة غائبة أو قديمة، راجع التثبيت وكرّر الاختبار. إذا لم يدعم العميل التصغير، أبق النافذة ظاهرة أو استخدم مسار قطع الاتصال الذي تحققت منه بصورة منفصلة. [استكشاف الأخطاء](../../README.md#if-the-proof-fails) · [فحوص الإعداد](../configuration.md#configuration-checks).

<a id="undo"></a>

إزالة المهام/استعادة العميل لا تقفل وحدة التحكم الحالية تلقائيًا. احفظ وأنهِ الأتمتة؛ اقفل المضيف يدويًا وتحقق من طلب الدخول عند وحدة التحكم، أو سجّل الخروج عمدًا لإنهاء التطبيقات. القفل يوقف أتمتة GUI.

## التراجع

نفّذ من المجلدين المستنسخين المناسبين. يزيل الأمر الأول المهام المجدولة على المضيف البعيد؛ ويعيد الثاني إعدادات العميل على الحاسوب المحلي نفسه وبحساب المستخدم نفسه.

```powershell
wscript.exe .\start-desktop-session-setup.vbs --uninstall
```

</div>





<div dir="ltr">

</div>
