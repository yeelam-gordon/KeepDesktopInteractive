# KeepDesktopInteractive — Автоматизация интерфейса Windows после отключения RDP

> **Предупреждение: передача сеанса на консоль оставляет удалённый рабочий стол Windows разблокированным. Любой, у кого есть доступ к физической клавиатуре или интерактивной консоли ВМ, может использовать сеанс без входа в Windows. Не используйте общий ПК, к которому могут подойти другие люди. Вы должны доверять администраторам Hyper-V и всем, кто может открыть VMConnect. Тестовая учётная запись или облачная ВМ не становится безопасной автоматически. Соблюдайте правила организации: это не автоматизация за заблокированным удалённым экраном и не обход политики блокировки.**

Автоматизация Windows прекращается после отключения RDP? Сохраните **уже открытый и разблокированный** сеанс для щелчков, ввода текста и снимков экрана существующих агентов computer-use или UI-тестов. Сбой ввода при свёрнутом окне — отдельный случай, требующий совместимого клиента и отдельной проверки. Нет встроенной интеграции или запуска агентов, хранения паролей и автоматического входа.

**Два компьютера:** удалённый хост — ПК/ВМ Windows, где выполняется автоматизация; локальный клиент — ПК Windows с RDP/Windows App. Нужны Windows PowerShell 5.1, VBScript и Git для клонирования. Установка на хосте требует одобрения администратора. На обоих компьютерах получите новую доверенную копию в личной папке текущего пользователя, а не в общей папке с правом записи.

```powershell
git clone https://github.com/yeelam-gordon/KeepDesktopInteractive.git "$env:LOCALAPPDATA\KeepDesktopInteractiveSource"
Set-Location "$env:LOCALAPPDATA\KeepDesktopInteractiveSource"
```

Откройте клонированную папку на каждом компьютере и выполняйте команды из неё. Первую команду запускают на удалённом хосте с одобрением повышения прав, вторую — на локальном клиенте.

```powershell
wscript.exe .\start-desktop-session-setup.vbs
```

```powershell
wscript.exe .\set-local-rdp-minimize-rendering.vbs
```

Полностью закройте удалённый клиент, откройте его снова и подключитесь. [Результаты установки](../configuration.md#quick-setup): на хосте `Installed: true` и `Status: Ready`, на клиенте `Succeeded: true`.

**Первая проверка:** обычным способом отключите RDP, подождите 30 секунд и подключитесь снова; диагностика запускается автоматически. Для отдельной проверки свёрнутого окна выполните команду ниже на удалённом хосте, сразу сверните окно клиента на 90 секунд, затем восстановите его. Проверка ждёт 60 секунд перед реальным вводом и захватом экрана.

```powershell
wscript.exe .\test-interactive-desktop-automation.vbs --minimized-test
```

На хосте откройте новый `%LOCALAPPDATA%\KeepDesktopInteractive\desktop-proof.json`. Ниже приведены ожидаемые поля для каждой проверки, а не результаты измерений в ходе этого обновления:

```json
{ "Passed": true, "Mode": "AfterDisconnect" }
```

```json
{ "Passed": true, "Mode": "WhileClientMinimized" }
```

Проверка свёрнутого окна действительна только если оно оставалось свёрнутым во время ввода и захвата экрана; хост не может наблюдать состояние клиента. Не публикуйте журналы и снимки: они могут содержать соседние области рабочего стола. [Подробности проверки](../configuration.md#verify-on-each-new-machine).

**Ограничения:** настройка описана для классического Remote Desktop Connection; поддержка Windows App зависит от версии. По сообщению сопровождающего, исходная пара клиент/хост прошла проверку свёрнутого окна до усиления защиты, но после развёртывания её не перепроверяли. Это не подтверждает поддержку всех клиентов. После перезагрузки войдите и разблокируйте сеанс один раз, затем запустите приложения и автоматизацию. Рабочие столы без графического интерфейса не поддерживаются. Удалённая блокировка, сон, выключение и выход из учётной записи могут остановить автоматизацию. [Все ограничения](../configuration.md#requirements-and-limitations).

При `Passed: false` прочитайте `Error`, `Stage` и журналы. Если результат отсутствует или устарел, проверьте установку и повторите тест. Если клиент не поддерживает свёрнутое окно, оставьте его видимым или используйте отдельно проверенный сценарий отключения. [Устранение неполадок](../../README.md#if-the-proof-fails) · [Проверки конфигурации](../configuration.md#configuration-checks).

**Отмена настройки:** выполняйте из соответствующих клонированных папок. Первая команда удаляет запланированные задачи с удалённого хоста; вторая восстанавливает настройки клиента на том же локальном ПК под тем же пользователем.

```powershell
wscript.exe .\start-desktop-session-setup.vbs --uninstall
```

```powershell
wscript.exe .\set-local-rdp-minimize-rendering.vbs --restore
```

Сохраните клиентский `%LOCALAPPDATA%\KeepDesktopInteractive\local-rdp-minimize-backup.json`, пока восстановление может понадобиться. Операции независимы и не удаляют диагностические данные.
