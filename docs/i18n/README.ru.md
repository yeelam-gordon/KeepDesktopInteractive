Для агентов и UI-тестов на существующем рабочем столе Windows: Windows App — клиент; Microsoft Dev Box может быть хостом, как и другой компьютер Windows с RDP.

<img src="../../assets/keep-desktop-interactive.png" width="320" alt="Концептуальная иллюстрация: сохраняйте щелчки и ввод после отключения; не следите за удалённым окном при сворачивании с проверенным совместимым клиентом; повторно используйте рабочий стол, где уже выполнен вход, без хранения паролей. Передача на консоль оставляет его разблокированным.">

Концептуальная иллюстрация с английскими подписями, не результат теста.

- **Сохраняйте щелчки, ввод и снимки.**
- **Не следите постоянно за соединением.**
- **Повторно используйте рабочий стол, где уже выполнен вход, и открытые приложения без хранения паролей.**

> **Передача оставляет удалённый рабочий стол разблокированным.** Тот, кто может управлять физической или интерактивной консолью ВМ, может использовать сеанс без входа в Windows. Не используйте доступный другим общий ПК или недоверенную консоль. Автоматизация не работает на заблокированном рабочем столе и не обходит правила. [Настройка и риски доступа](../configuration.md).

На обоих компьютерах нужна Windows. На хосте уже выполнен вход, рабочий стол разблокирован; он не должен переходить в спящий режим, и правила должны разрешать такое использование. Нужны одобрение администратора хоста, Git, Windows PowerShell 5.1 и VBScript.

Установленная диагностика пытается выполнить щелчки, ввод и снимок примерно через 10 секунд после каждого отключения RDP настроенного пользователя, включая обычную работу, и может мешать агенту.

<a id="setup"></a>

## Настройте оба компьютера

На обоих компьютерах клонируйте новую доверенную копию в личную папку текущего пользователя, не в общую папку с правом записи. Откройте `%LOCALAPPDATA%\KeepDesktopInteractiveSource` в Проводнике и дважды щёлкните соответствующий файл запуска.

```powershell
git clone https://github.com/yeelam-gordon/KeepDesktopInteractive.git "$env:LOCALAPPDATA\KeepDesktopInteractiveSource"
```

| Удалённый хост / Локальный клиент | |
| --- | --- |
| Удалённый хост | `start-desktop-session-setup.vbs` — одобрите повышение прав |
| Локальный клиент | `set-local-rdp-minimize-rendering.vbs` — полностью закройте Windows App/RDP, откройте и подключитесь снова |

[Результаты установки](../configuration.md#quick-setup): Удалённый хост `%LOCALAPPDATA%\KeepDesktopInteractive\elevation-result.json` → `%ProgramData%\KeepDesktopInteractive\setup-result.json`: `Installed: true`, `Status: Ready`; Локальный клиент `%LOCALAPPDATA%\KeepDesktopInteractive\local-rdp-minimize-result.json`: `Succeeded: true`.

<a id="proof"></a>

## Проверьте реальный ввод

До теста запишите время начала, остановите другую UI-автоматизацию, сохраните важную работу и уберите конфиденциальные окна; отключение запускает диагностику. Время изменения файла должно быть позже начала теста, а значения `Passed` и `Mode` — соответствовать этому тесту; затем проверьте щелчки, ввод текста и снимки экрана в безопасной задаче при итоговом разрешении консоли. Диагностика не доказывает работу всех приложений.

Отключитесь на 30 секунд и подключитесь снова. На хосте проверьте обновлённый для этого теста `%LOCALAPPDATA%\KeepDesktopInteractive\desktop-proof.json`: `Passed: true`, `Mode: AfterDisconnect`.

Сворачивание зависит от условий: отдельно выполните [90-секундный тест / 60-секундную задержку](../configuration.md#verify-on-each-new-machine) для `WhileClientMinimized`. При сбое оставьте окно видимым.

<a id="limits"></a>

- После перезагрузки вручную войдите, разблокируйте и запустите приложения; автоматического входа нет. Удалённая блокировка, сон и выход могут остановить работу.
- Совместимость зависит от клиента и версии, не общая сертификация Dev Box: [данные](../configuration.md#reported-compatibility-evidence).
- Свёрнутое окно Windows Sandbox с работающим гостем: **НЕ ПРОВЕРЕНО**; [эксперимент](../configuration.md#sandbox-minimized-window-experiment), не инструкция RDP.

## Сбои и отмена

Сбой, отсутствующий или старый результат? Проверьте `Error`, `Stage` и установку, затем повторите тест. [Устранение неполадок](../configuration.md#proof-and-setup-troubleshooting) · [Проверки конфигурации](../configuration.md#configuration-checks)

<a id="undo"></a>

Удаление задач хоста и восстановление реестра клиента не блокируют консоль. Сохраните работу и завершите автоматизацию; заблокируйте хост и проверьте требование входа либо намеренно выйдите из учётной записи для завершения приложений.
